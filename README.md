# CareAuth
 
Healthcare prior-authorization workflow platform.
 
## What it does
Providers (clinics) submit requests for medical procedures.
Reviewers at the insurer approve, deny or ask for more information.
Admins manage users and coverage rules.
 
## Tech stack
ASP.NET Core Web API (.NET 10), EF Core, SQL Server, Docker.
Planned: React + TypeScript, Azure, AI features.
 
## Architecture
Layered (clean) architecture: Api, Application, Domain, Infrastructure.
 
## Status
In development. All data in this project is fictional.
